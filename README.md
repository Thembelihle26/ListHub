List Hub

A Kotlin Android app that helps users organise, manage, and track their daily tasks with offline sync, push notifications, and multi-language support.

Features

* User registration and login with encrypted passwords (Firebase Authentication)
* Single Sign-On (SSO) with Google Sign-In
* Create, edit, and delete tasks with due dates and priorities
* Natural language task input (e.g., "Meet lecturer tomorrow at 2 PM")
* Offline mode with automatic sync using Firebase Firestore
* Push notifications for task reminders and daily planner alerts
* Multi-language support (English, Afrikaans, isiZulu)
* Gamification (Karma points and level system)
* FocusFlow daily planner with AI-driven task suggestions
* Dark/Light theme toggle
* Colour-coded categories for visual organisationClean and intuitive user interface with Peach, White, and Purple colours
* Focus Mode
* Productivity Dashboard 

Tech Stack

* Language: Kotlin
* IDE: Android Studio/Blue Stacks 
* Minimum SDK: API 26 (Android 8.0 Oreo)
* Architecture: MVVM (Model-View-ViewModel) + Repository Pattern
* Authentication: Firebase Authentication
* Database: Firebase Firestore (Real-time + Offline)
* REST API: Google Tasks API
* Networking: Retrofit + OkHttp
* Push Notifications: Firebase Cloud Messaging (FCM)
* CI/CD: GitHub Actions
